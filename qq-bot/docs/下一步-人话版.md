## 一、先说今天已经定下来的新规矩（这条我已经改完代码了）

**你的原话**：「签名和昵称和动态（QQ空间）是他自己决定什么时候发，我只审批。」

以前是这样：

```
你说「改个签名」 → 她拟一版 → 你说「可以」 → 她改
（她从来不主动提，你不开口她就不动）
```

现在是：

```
她自己想改 → 她自己拟好 → 她念给你听 → 你说「行」 → 她改
（时机归她，执行权归你）
```

- 会有一种新情况：**她会主动冒出来说**「我想把签名换成这个，行不行」「今天想发条说说」。
- 你只回一个字：**行 / 不行**（「可以」「就这个」「改」「发」都算点头）。
- 每天有次数上限：**说说 3 条、资料（签名/昵称）3 次**。到上限她只能说明天再说。
- ⚠️ **有一条是程序兜底的**：她**不许**在你说行之前说"已经改了/发了"。她要是嘴快说了，程序会当场戳穿，并在她那条消息后面补一句实话（"这一轮我没真的改，账号那边什么都没发生"）。这条是这两天抓她撒谎抓出来的，已经上线。

**你要做的：什么都不用做**（配置我已经写好）。等下次重启，她就会开始主动提。

## 二、然后是我之前说的「闲聊留 QQ、干活派 agent」—— 人话版

### 现在是什么样

**一个程序干所有事**。她想查东西、截图、改签名、发说说，用的都是我事先给她写好的**那几个固定工具**。

后果就是这两天你看到的：

- 想加一个新本事（比如"改签名"），我得写代码，你还得重启；
- 有些事她其实做不了，但她会**嘴上说做了**（因为"说话"和"动手"之间没有强制关系）。

### 我建议变成什么样

**加一个"外援"。**

```
你 → 她（QQ 里，还是她本人：人格、记忆、秒回都不变）
       │
       ├─ 闲聊、陪聊、撒娇、记事儿   → 她自己处理（和现在完全一样）
       │
       └─ 「去查一下…」「帮我写个脚本」「看看我屏幕」
                    ↓  把活转包出去
              外援 agent（Codex / Claude Code 那种，
              能在你电脑上真正读写文件、跑命令、上网查）
                    ↓  把结果交回来
              她用她自己的话告诉你（并附上原始结果）
```

**好处**：

- 能做的事**一下子多一个量级** —— 不用我一件一件写代码了（今天为了"改签名"我写了 23KB 代码、你重启了四次；换成外援，那是一次调用的事）。
- **"她到底做没做"有据可查**：外援干的每一步都有记录，你可以查。
- 顺便：外援是现成的，**我已经把它跑通了**（`claude --print` 一句话任务 997ms 返回，带 session 号，能接着上次继续聊）。

**代价（说清楚）**：

- **慢**：派出去干的活要几秒到几分钟。所以只能用于"干活"，**闲聊绝不能走这条路**（不然秒回没了）。
- **一次只派一件**：你内存紧（常剩 1GB 上下），不能同时跑好几个。
- **可能要你点头**：动系统、装东西这类，仍按现在的审批规矩来。

**我要做的**：一个小模块（把活交出去 + 把结果收回来）、一个开关、一份日志。约 **1~2 天**。

## 三、顺便：桌宠**已经装好了**，只是关着

机器上有一个 DSH 的桌宠插件（`@linxin666/dsh-pet`），现在 `disabled: true`。它有的东西正好是你要的：

| 它自带的 | 对应你的需求 |
| --- | --- |
| **鲸鱼形象**（Live2D / 精灵图） | 「Live2D 形象」 |
| **好感度 9 级**：幼鲸 → 伙伴 → 挚友 → 深海羁绊 → 心有灵犀 → 传说羁绊 → 神话羁绊 → 永恒之契 → **鲸生共渡** | 「像妹居物语那样有…好感度」 |
| 摸头 +1、喂小鱼干 +5（鱼干经济） | 互动 |
| 跟着 agent 状态动：等待/思考/跑工具/成功/出错 | 你知道她此刻在干什么 |
| 状态气泡 + 碎碎念、可改名、可拖动、可隐藏 | 陪伴感 |

**打开它 = 改一行配置 + 重启 DSH，10 分钟见效。** 而且它跟的正是"agent 在干活"的状态 ——
所以上面第二部分做完之后，**她干活时桌宠就会自己跑动、思考、庆祝**。

它**不覆盖**的（要另外做）：独立 exe、读屏幕陪你打游戏、语音、真实 Live2D 模型（可以从它的 Workshop 装）。

## 四、所以顺序建议

1. **现在**：签名/昵称/说说的新规矩已经写好了，重启后她就会主动提 —— 你只审批。
2. **下一步（10 分钟）**：把桌宠打开，你立刻能看到她 + 好感度。
3. **再下一步（1~2 天）**：agent 转包，让她真能干活。
4. **最后**：读屏幕陪玩、语音。

## 附：这几天的账（你要是想知道"为什么老出问题"）

| 你看到的现象 | 真正的原因 |
| --- | --- |
| 说"点完啦"其实没点 | 模型会描述一个它没做的动作 —— 现在有程序兜底（谎话闸）+ 关键动作由代码直接执行 |

| 改名说"次数上限" | 真的到上限了：代码默认"改资料一天 1 次"，而签名已经用掉了 → 已调到 3 次 |

这一串全是**我的**错，不是她的"性格问题"。修完之后自测 **595/595**（两个 node 解释器都跑）。
